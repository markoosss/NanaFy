# Proposal

## Why

The family needs one shared, easy-to-use place to coordinate the cat's daily care and keep reliable records of what has been done and when. A mobile-first web app with individual family profiles will make care routines visible across devices and reduce missed or duplicated tasks.

## What Changes

- Create a shared web app for feeding, medication, extra care tasks, calendar events, and notes.
- Add individual profiles with password-based access, first-use activation codes, and role-based permissions.
- Record who completed each care activity and when, with a history that the family can review.
- Provide a mobile-first interface and ask whether the user is on mobile or PC at each login.
- Allow Marcos to administer family profiles, activation codes, and care schedules; keep guest access limited to viewing and recording care.
- Make routine data editable through the app and keep the database structure understandable in the project code.

## Capabilities

### New Capabilities

- `cat-care-management`: Shared cat-care schedules, completion history, calendar, notes, family profiles, and access permissions.

### Modified Capabilities

None.

## Impact

- Introduces a mobile-first web application and a persistent shared database.
- Requires authenticated access, profile/role management, and synchronized records across devices.
- No existing application code or capabilities are present; implementation technologies and hosting remain to be selected in the design.
